# Contributing

## Setup

```bash
pnpm install
pnpm check
```

## Standards

- Add tests for all behavior changes.
- Keep public API changes documented in README.
- Add a Changeset for user-facing changes.
- Ensure coverage remains >= 85% globally.
- For modified source files, keep line coverage >= 80%.

## Pull Requests

- Use clear commit messages.
- Include test evidence in PR description.
- Do not commit secrets.
